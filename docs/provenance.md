# Source provenance

This repository is a compact source release for the two JevGPT main-table rows. It contains the reachable reader/search/runtime dependencies and their relevant offline tests, plus portable launch, data and evaluation commands.

The ranking implementation comes from the frozen source archive of `neuclir-task-hybrid50-unified-20261005`. Its imported source hashes were checked against that cohort's protocol. All 105 topics used the same reader and search service. The QA entry and its shared dependencies are byte-identical to the BCP worktree's runtime available during release preparation. The BCP protocols preserve the run settings and selected-output hashes. `provenance/paper.json` records the evidence for both tasks.

The main entry points are:

- QA: `runtime/pi-serini/src/extensions/pi_search_jev_hybrid_v2.ts`.
- Ranking: `runtime/pi-serini/src/extensions/pi_search_jev_unified_v1.ts`, dispatching to `pi_search_jev_ranking_autoscan_v1.ts`.
- Hybrid BCP retrieval: `runtime/pi-serini/src/pi-search/searcher/adapters/passage_bm25/hybrid.ts`.
- Hybrid NeuCLIR retrieval: `services/neuclir_hybrid.py`.

The reader, prompts, local judgments, retrieval fusion, evidence coordinates and background scans retain their imported implementation. The existing internal names `Jev` and `Assay` identify historical experiment artifacts; the paper's display name is JevGPT.

## Packaging changes

- Added a portable Python experiment launcher using the original BCP orchestration and NeuCLIR worker. Paths, model provider, index locations and the search-service URL are explicit arguments or environment settings.
- Parameterized the NeuCLIR worker's model name and relocated its request-settings audit hook. The hook records model/effort and a request hash without recording credentials or changing requests.
- Removed unrelated benchmark registrations and their manifests. Reduced npm scripts to the included build, test and type-check commands.
- Changed one test's machine-specific Python path to `JEV_SPLITTER_PYTHON` or `python3`.
- Replaced the BrowseComp-Plus questions used as inputs in one auto-scan test with invented questions of the same structure, so the release contains no benchmark question in plain text.
- Extracted the official BCP grader prompt and parser; added a separate portable evaluator and a stdlib NeuCLIR scorer. The latter matches all 105 original per-topic metric values.
- Added UTF-16 document-length export, dataset preparation and explicit missing-usage accounting.

`provenance/source-files.json` gives each imported file's original hash and records any packaging change. `public-files.txt` is the release inventory; `provenance/file-hashes.json` verifies every listed file except itself.

## Results

`results/browsecomp.jsonl` retains 830 selected records with correctness, resources, attempt/cohort IDs and original answer/grade hashes. Every selected answer and grade was checked against the paper snapshot before export. The referenced raw result hash was checked as well.

`results/neuclir.jsonl` retains 105 first-outcome records with submitted document IDs, resources, metrics and original result/audit hashes. The imported summary and TREC ranking hashes were checked against the paper snapshot; each result and audit was checked against the original seal. The released TREC file is unchanged.

Only JevGPT records are included. The ledger supports exact table reconstruction.
